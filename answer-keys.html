Answer key tool

Internal tool: not linked from the site. Pick a subject, then press the correct letter for each question. Your work is saved in this browser as you go.

Shortcuts: A–E set the answer and move on, ← back, → skip, X mark as bad question. Dashed orange = suggested by the source file (not verified).

After downloading, replace data/keys/<subject>.json with the file, then set "ready": true for that subject in data/questions/index.json.
